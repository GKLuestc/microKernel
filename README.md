## lab1 任务
lab1的内容分为三个部分：
* part1 简单介绍了汇编语言，物理内存地址空间，BIOS。
* part2 介绍了BIOS从磁盘0号扇区读取 boot loader 到 0x7c00 处，并将 cs:ip 设置为 0x7c00。之后boot loader主要完成：
  a.创建两个全局描述符表项（代码段和数据段），然后设置CR0进入保护模式；
  b.从磁盘1号扇区读取4KB到0x10000处，并且识别kernel的ELF文件，加载内核各个段到指定位置。
  
* part3主要介绍进入内核后的一些操作：
  a. 首先会开启分页模式。
  b. 格式化输出字符串的原理。本质还是往物理内存0xB8000起始的显存写数据。
  c. 函数调用过程。
